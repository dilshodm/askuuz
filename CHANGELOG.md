# CHANGELOG

Все значительные изменения в этом проекте будут задокументированы в этом файле.

## [Unreleased]

### 🐛 Исправлено

- **Водоснабжение**: обновление данных падало с ошибкой
  `unsupported operand type(s) for +: 'int' and 'NoneType'`, если API uzsuv.uz
  возвращал `null` вместо `0`. Так происходит для любого периода без
  перерасчёта (`corr`), без начисления (`chrg`), без платежа (`psum`),
  без показаний (`om3`) и без сальдо (`sld_sum`). Все числовые поля ответа
  теперь проходят через `_as_number()`.

### 🧪 Тесты

- Добавлен каталог `tests/` и набор тестов для клиента водоснабжения
  (24 теста, 100% покрытие `api/water.py`)
- Добавлены `pytest.ini` и `requirements-dev.txt` (упоминался в CONTRIBUTING.md,
  но отсутствовал в репозитории)

## [1.0.0] - 2026-01-30

### ✨ Добавлено

- **Основная функциональность**
  - Поддержка 4 сервисов: Электроэнергия, Водоснабжение, ТБО, Управляющая компания
  - Получение информации о балансе, потреблении и начисленной сумме
  - Автоматическое обновление каждые 12 часов

- **Безопасность и валидация**
  - Валидация учётных данных перед сохранением конфигурации
  - Проверка на дубликаты (по сервису, логину и лицевому счёту)
  - Безопасное хранение паролей в Home Assistant

- **Интерфейс пользователя**
  - Кнопка "Обновить данные" для каждого сервиса
  - Три сенсора на каждый сервис (баланс, показатели, начисления)
  - Локализация на 3 языках (Русский, English, O'zbekcha)

- **Автоматизации**
  - Сервис `askuuz.refresh_data` для обновления данных
  - Опциональный параметр `entry_id` для выборочного обновления
  - Возможность обновить все конфигурации одновременно

- **Документация**
  - Полный README.md с примерами использования
  - Документация по установке и настройке
  - Примеры автоматизаций

### 🔧 Технические детали

- Архитектура на основе DataUpdateCoordinator для стабильной работы
- Поддержка воссоздания сущностей при разрыве соединения
- Кеширование последних успешных данных
- Обработка ошибок 401/403 с автоматическим переподключением

### 📝 Примечания

- Первый релиз компонента
- Все основные функции реализованы и протестированы
- Готов к использованию в production
