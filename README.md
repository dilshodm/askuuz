# ASKU Uzbekistan Utilities Integration

Интеграция Home Assistant для получения данных о потреблении коммунальных услуг (электроэнергия, вода, ТБО, газ, управляющая компания) в Узбекистане через портал ASKU.uz.

## 🌍 Поддерживаемые сервисы

- **Электроэнергия** (het.uz)
- **Водоснабжение** (uzsuv.uz)
- **ТБО** Вывоз твёрдых бытовых отходов (tozamakon.eco)
- **Газоснабжение** (kommunal.uz) — отдельной услугой, договор с УК не требуется
- **Управляющая компания** (kommunal.uz) с опциональной поддержкой газоснабжения

## ✨ Возможности

✅ Получение актуальной информации о балансе счёта  
✅ Отслеживание потребления ресурсов (кВт·ч, м³, и т.д.)  
✅ Просмотр начисленной суммы  
✅ Валидация учётных данных перед сохранением  
✅ Проверка на дубликаты конфигураций  
✅ Кнопка обновления данных для каждого сервиса  
✅ Сервис для автоматизаций  
✅ Локализация на 3 языках (Русский, English, O'zbekcha)  
✅ Автоматическое обновление каждые 12 часов

## 🛠️ Установка

### Способ 1: Через HACS (рекомендуется)

1. Откройте HACS → Integrations
2. Нажмите "Explore & Download Repositories"
3. Найдите "ASKU Uzbekistan Utilities"
4. Нажмите "Download"
5. Перезагрузите Home Assistant

### Способ 2: Ручная установка

1. Скачайте папку `askuuz` 
2. Поместите её в `/config/custom_components/`
3. Перезагрузите Home Assistant

## 🔧 Настройка

### Через UI (рекомендуется)

1. Перейдите в **Settings** → **Devices & Services**
2. Нажмите **Create Automation** → **ASKU Uzbekistan Utilities**
3. Выберите услугу (Электроэнергия, Вода, ТБО, Газ, УК)
4. Введите учётные данные (логин, пароль, лицевой счёт)
5. Система проверит данные и создаст конфигурацию

### Проверки при добавлении

✓ **Валидация данных** - система попробует залогиниться и не сохранит конфигурацию при ошибке  
✓ **Проверка дубликатов** - нельзя добавить две одинаковые конфигурации (по сервису, логину и счёту)

## 📊 Сущности

Каждый сервис создаёт следующие сущности:

### Сенсоры (3 штуки)

| Сенсор | Описание | Единица |
|--------|---------|---------|
| `consumption` | Показатели потребления | кВт·ч / м³ / и т.д. |
| `accrual` | Начисленная сумма | UZS |
| `balance` | Баланс счёта | UZS |

### Кнопки (1 штука)

| Кнопка | Описание |
|--------|---------|
| `refresh_data` | Обновить данные немедленно |

## 🎯 Использование

### Просмотр данных в UI

1. Откройте **Home** → **Devices & Services**
2. Найдите устройство (например, "ASKU UZ Electricity 12345678")
3. Просмотрите все сенсоры и кнопки

### Кнопка обновления

Каждое устройство имеет кнопку **Обновить данные**. При нажатии данные немедленно обновляются с сервера.

### Сервис для автоматизаций

#### Обновить ВСЕ конфигурации

```yaml
service: askuuz.refresh_data
```

#### Обновить конкретную конфигурацию

```yaml
service: askuuz.refresh_data
data:
  entry_id: "abc123def456"  # ID конфигурации из Developer Tools
```

## 📝 Примеры автоматизаций

### Пример 1: Ежедневное обновление в определённое время

```yaml
automation:
  - alias: "Обновить данные утилит в 10:00"
    trigger:
      platform: time
      at: "10:00:00"
    action:
      service: askuuz.refresh_data
```

### Пример 2: Обновление при включении Home Assistant

```yaml
automation:
  - alias: "Обновить утилиты при старте HA"
    trigger:
      platform: homeassistant
      event: startup
    action:
      service: askuuz.refresh_data
```

### Пример 3: Обновление по расписанию несколько раз в день

```yaml
automation:
  - alias: "Обновить утилиты 4 раза в день"
    trigger:
      platform: time
      at:
        - "06:00:00"
        - "12:00:00"
        - "18:00:00"
        - "22:00:00"
    action:
      service: askuuz.refresh_data
```

### Пример 4: Обновление по расписанию (синтаксис v2)

```yaml
automation: !include automations.yaml
```

В файле `automations.yaml`:

```yaml
- alias: Обновить данные утилит
  description: Обновить данные каждые 12 часов
  trigger:
    - platform: homeassistant
      event: startup
    - platform: time_pattern
      hours: "/12"
  condition: []
  action:
    - service: askuuz.refresh_data
      data: {}
```

## 🔐 Безопасность

- ✅ Учётные данные хранятся в защищённом формате Home Assistant
- ✅ Пароли **никогда** не выводятся в логи
- ✅ Подключение только по HTTPS

## ⚙️ Расширенная конфигурация

### Просмотр ID конфигурации

Для получения `entry_id` конкретной конфигурации:

1. Перейдите в **Developer Tools** → **States**
2. Найдите сенсор вашего устройства (например, `sensor.asku_uz_electricity_12345678_balance`)
3. ID конфигурации находится в параметре `entry_id` в атрибутах сущности

### Просмотр логов

```bash
# Просмотр логов интеграции
grep askuuz /var/log/homeassistant/home-assistant.log

# Или через UI:
# Settings → System → Logs
```

## 🐛 Решение проблем

### Ошибка: "Неверный логин или пароль"

- Проверьте правильность введённых данных
- Убедитесь, что учётная запись не заблокирована на ASKU.uz
- Попробуйте переустановить конфигурацию

### Ошибка: "Запись с такой услугой, логином и счётом уже существует"

- Удалите старую конфигурацию перед добавлением новой
- Settings → Devices & Services → найдите конфигурацию → Delete

### Данные не обновляются

- Проверьте интернет-соединение
- Нажмите кнопку **Обновить данные** вручную
- Перезагрузите Home Assistant
- Проверьте логи в Developer Tools

### Сервис `askuuz.refresh_data` выдаёт ошибку

- Убедитесь, что вы НЕ указываете `entry_id` (или указываете правильный)
- Не обязательно передавать `entry_id` - сервис обновит все конфигурации

## 🔄 Цикл обновления данных

- **Интервал обновления**: 12 часов
- **Попытки переподключения**: автоматические при разрыве соединения
- **Кеширование**: последние успешные данные при ошибке API
- **Максимальное время ответа**: 30 секунд
